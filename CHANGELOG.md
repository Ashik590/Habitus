# Changelog

## 0.1.0 — First release candidate

- Timed spoken translation practice across CEFR levels A1–C2.
- Local Whisper transcription and Gemini evaluation with actionable feedback.
- Account registration, login, and cookie-based session refresh.
- Learning dashboard with speaking metrics and equal-weight competency scores.
- Profile pictures with a built-in default avatar.
- Responsive home page, Mount Fuji imagery, and developer footer.
- Docker deployment serving the frontend and API together.
- Optional Supabase Storage for persistent uploaded pictures.

### Known limitations

- Email ownership verification and password recovery are not implemented.
- AI responses may be delayed by provider timeouts or quotas.
- Free hosting may sleep, and the 512 MB memory budget needs deployment verification.
- The competency score is an application progress estimate, not CEFR certification.
